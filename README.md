# 确定要注销地球online账号？

一个单文件网页。白底黑字的确认弹窗，绿色「否」和红色「是」。

## 在线访问

https://excuse-2580.github.io/earth-online/

## 玩法

点「是」不会真的结束，会一层层套下去：

1. 确定要注销地球online账号？
2. 真的确定吗？
3. 最后一次确认。真的要注销吗？
4. **系统检测到你在笑。** 仍要继续注销吗？
5. 那……真的再见了？

走到最后一步才黑屏，依次播报：

```
正在释放资源…
正在回收 37.2 万亿个细胞…
正在解除 全部社交绑定…
正在清理 未完成的心愿…
注销完成。
```

然后定格：

> **开玩笑的。**
> 地球online 不支持注销。你还得继续玩。

点「否」（或按 `Esc`）则是「已取消注销 / 欢迎回到地球online」，附一张账号卡片：
服务器 Earth·亚洲节点、运行状态正常、当前时间、**本次在线时长实时跳动**、可注销：**否**。

## 关于这个梗

「注销账号」在现实里对应的是一件很重的事，这个网页的笑点正是建立在这个映射上。
所以落点放在了反面——走到最后不是黑屏结束，而是被推回「继续」这一边。
真正的结局是那个「否」。

如果你或身边的人正经历情绪低谷，这些可以打：

| 热线 | 说明 |
|---|---|
| **12356** | 全国统一心理援助热线，24 小时、免费、可匿名 |
| **400-161-9995** | 希望 24 热线，7×24 小时生命危机干预 |
| **12355** | 共青团青少年服务台 |

不是只有「很严重」才能打。失眠、情绪长期低落、单纯想找个人说话，都可以。

## 技术

单文件 `index.html`，零依赖零构建，双击即可打开。

- 纯 HTML + CSS + 原生 JS，无框架、无外链资源
- favicon 为内联 SVG，不会 404
- 响应式，手机端按钮 143×54px（够大好点），无横向溢出
- 支持 `prefers-reduced-motion`，动画自动关闭

## 本地运行

```bash
python3 -m http.server 8000
# 或直接双击 index.html
```
